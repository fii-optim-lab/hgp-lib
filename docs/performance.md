# Performance

Benchmark reports of hgp-lib: how the evaluation backends compare, and how the versions compare.
The default values of the backend options were chosen from these reports, over several runs on several machines.

The reports are produced by the benchmark suites in `benchmarks/`; see `benchmarks/README.md` for how to run them.

## Evaluation backends

Every option combination of every backend, on the same scenarios, from `benchmarks/benchmark_backends.py`.

## Versions

The default benchmark suite across hgp-lib versions, from `benchmarks/benchmark.py` and `benchmarks/compare_results.py`.
